## 2. 本轮已修复的问题

1. **缺少测试输入**：恢复原 7 个协议向量并补充 2 个 CRC 正确的异常分片，修正测试路径和库存断言；保留来源与 SHA256。
2. **新编译器声明冲突**：统一两个函数定义与头文件中的数组参数声明，原生 GCC 8.1/13.1 均通过 37 项存图测试。
3. **测试等待竞态**：等待真实组帧状态后再设置短过期窗口，避免“报文已计数但尚未组帧”导致偶发失败；针对性连续 5 次回归。
4. **只跑一部分却误读为全部通过**：增加完整离线检查入口，显式开发跳过模式标记为 `pass_partial`；最终完整运行标记为 `pass`。
5. **工具路径与链接回执**：统一 ARM/Vivado 工具查找，支持环境变量；识别链接器 map 中 `LOAD linker stubs` 的合成记录，其他输入仍严格核对。两核、FSBL 和 BOOT 实际构建并逐输入留证。
6. **成功 PL 策略藏在缓存目录**：将历史成功的 Explore/AggressiveExplore 指令加入正式构建；新增综合报告输出；在普通 Tcl 中核对按键同步器端点。
7. **生成文件污染根目录**：让 IP 生成过程在输出工作区运行；包检查忽略明确的工具缓存，ZIP 按完整清单导出，另拒绝未登记交付文件。
8. **技能陈旧和假绿边界**：移除“单钟域免查 CDC”等过度概括；未知 CDC 行返回 `incomplete`；移植自测只对哈希一致的固定样本作固定资源断言。
9. **参考值没有实际值比较入口**：增加带输入哈希和独立原始证据要求的数值比较器，检查完整 logits/检测框、缺失项和非法值。观察模板留空，避免伪装成实测。
10. **新手命令不完整**：统一虚拟环境用法，明确环境变量作用范围，修正 PowerShell 5.1 空参数传递，补齐解压后重建环境、写卡回读和版本选择说明。

## 3. 尚未关闭的事实缺口

- 当前集成版本的冷启动、持续运行、实际摄像头/HDMI/音频、机械跟随和 SD 存图日志待核验。用户已说明有日志、稍后提供路径。接收后应记录文件指纹、时间、固件与输入身份、测试条件和失败项。
- 新 PL 时序为正不等于完成工程签核。CDC 中的 1 个 Unknown、1 个 Unsafe，I/O 延时覆盖及方法学告警仍需按端点分析。没有足够板级条件时，不通过添加任意延时或 false path 使报告表面通过。
- 包内三个固定样本尚无本轮完整独立 logits/检测框输出。旧历史输入不同，不能改名复用成当前对拍。比较器自身通过不关闭此项。
- 本轮新编译 ELF/BOOT/bit 没有混入 `board/firmware`，也没有被写卡或下载；它们的硬件配对与现场验证另需完成。当前发布镜像哈希保持不变。

因此，本次交付结论是：文档、技能、构建可复现性和离线验证已显著补齐，当前版本整机实测与完整工程签核仍有明确待办。不能仅以材料存在或测试数量替代功能正确性证明。
