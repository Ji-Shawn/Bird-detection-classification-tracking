# 大模型协作记录摘要

本文件是为工程交付整理的协作摘要，覆盖与当前 M51 功能有关的用户要求、实现选择和验证边界。它不是完整聊天原文或系统自动导出的逐条记录，也不包含账号、设备序列号或个人文件路径。

| --- | --- |

| 响应与稳定 | 修正扫描接管、失配恢复和回中过程；加入在线视觉参数、扫描速度、预览发布频率和运动前馈调试。反馈信号仍为图像及指令历史，未增加编码器。 |

## 协作方法

用户决定功能范围与设备使用方式；模型协助定位源码和实际构建入口、提出实现、修改持久化源码或生成 overlay、运行适当的原生验证及 ARM 构建，并记录源码与产物指纹。生成的中间 C 文件不作为唯一修改点，避免下一次构建覆盖修复。

对需要区分的现象曾分别询问上位机与 HDMI 是否同时停帧、目标失锁与视觉分数的关系、摄像头接线和日期来源等。用户确认的限制优先：麦克风固定基座、无编码器、原版本保留，以及只改变当次要求的功能。

验证中区分主机仿真、原生函数集成、ARM 编译、镜像配对、SD 文件写入、板卡冷启动和实际机械表现。确定性输入的测试用于判断状态机、时效和文件写入行为，不当作现场模型准确率或机械跟随结论。

## 95% 修订的实际范围

最新修订只把 `SD_ARCHIVE_MIN_SSD_SCORE` 从 `0.8f` 改为 `0.95f`。原有照片资格状态机、目标身份、标签时效、队列与停止条件继续沿用。重新构建 Core0 后，其他 34 个对象未变，Core1、PL 和模型未变；镜像及其指纹相应更新。

95% 边界、80%/90% 拒绝、无效分数、低分撤销、目标身份和时间异常均有原生覆盖。实际存图集成使用真实生产函数、真实 FatFs 和稀疏块设备测试夹具。物理卡延迟、光学清晰度、误检率与机械运动仍需要设备实测。

## 仍需使用者提供的工程条件

重建需要相应版本的 Xilinx 工具、ARM 工具链及运行依赖。模型训练数据、训练授权和部署权重的统一开放许可不在现有工程证据中；因此本包不把已有模型指标等同于重新训练结果，也不擅自为项目所有内容指定一个覆盖全部第三方的许可证。

本次打包没有代表用户建立远端仓库、推送 GitHub、连接板卡或更新 SD 卡。包内说明和校验结果用于帮助用户审阅和自行上传。
