## 2. 自我纠错轨迹(按时间序,含原始误判与翻盘证据)

**纠错 1:"多瓦片 PW 第 2 帧挂"——误判为引擎 bug,实为环境伪装**
- 初始假设(交接文档):引擎多瓦片帧重启缺陷。
- 纠错动作:诊断快照 → 失败位置随机漂移;单瓦片 L02 连跑 5 次出现"挂/全错/过"三种结局 → 排除结构性 bug;A/B 对照旧 bit 同样失败;**抽查 DDR 抓到单字节篡改**。
- 修正结论:非引擎问题 = DDR 数据腐烂 + DAP wedge。**经验:判案第一实验永远是"已知好 bit + 新灌数据"。**

**纠错 2:"装载循环 PIPELINE off 是元凶"——抓了真凶的替身**
- 证据链:撤除 PIPELINE off 后 HLS 自动流水化 6 循环(214-376),装回仍挂 → 自首条判断正确但非主因。
- ILA 波形:引擎寄存器全对、守协议背压,**S2MM 中途永久停收**(DMASR 无错) → 引擎是受害者。
- 好/坏引擎对照捕获:beat 稀疏模式相同 → 排除 beat 稀疏;最终靠**结构回退(保守融合)通过全部回归**。**经验:cosim 绿不等于上板能跑;流时序类 bug 只有 ILA 和上板能判。**

**纠错 3:"流水化循环有毒"——被板子劣化污染的错误归因**
- Step B/B2(流水化 MAC)挂 → 暂定"流水即毒"。
- 用户断电 POR 后重测:B2' **62/62 全绿 @100MHz** → 证伪。真实规则收窄为:**流操作不可入流水循环,纯计算循环可流水**。
- **经验:环境(板子健康度)本身是变量;劣化期的所有失败归因都要 POR 后复测。**

**纠错 4:"perf 版确定性错数据是逻辑 bug"——实为边际 hold 时序**
- 现象:全流水版不挂了,但同位置确定性错(maxd=255,L01 DW 也错——而 DW 源没动)。
- 排除逻辑后查构建:该版 **WHS=+0.017ns** → 判为边际保持时间问题,与逻辑无关。
- **经验:WHS <0.05ns 的构建不可信;先看时序报告再怀疑代码。**

**纠错 5:64 位化"改 MM 宽就够"——被静默补零打脸**
- 只设 `c_m_axi_*_data_width=64`,集成后引擎 TDATA 被自动补零(`{32{1'b0},...}`),HDL 自检照不到。
- 补设流口位宽参数后,检查 system.v 线宽 [63:0] 才放行。
- **经验:集成后必须查生成网表的实际线宽,不查会死得无声无息。**

**纠错 6:手写 RTL "异步读大数组无所谓"——704K LUT 学费**
- 组合块 72 个异步读口 → 读 mux 爆炸(超编 13 倍)。
- 独立综合三个变体对照:2D 数组(1037 LUT mux)/ 1D+distributed(RAMD64E ✓)/ 宽字整字访问(最终形态)。
- **经验:每拍整字读写、1R1W 是唯一安全形态;多维 unpacked 数组不推断存储。**

## 3. 智能体工作流设计(模型侧)

```
读交接 → 恢复现场(bit/ELF/板状态核验)→ TodoList 阶段化
→ 判别实验优先(最小可复现、单变量对照)→ 后台长任务(构建/回归并行)
→ 证据链写入交接(含被推翻结论的原文与反例)→ SKILL.md 沉淀通用规则
```

关键设计点:
- **黄金回归作为唯一门禁**:62 项零差异 + 链式 top1,任何中间结论以它为准;
- **对照纪律**:A/B bit、单瓦片 vs 多瓦片、100MHz vs 降频、带不带 ILA——每次只动一个变量;
- **长任务后台化**:Vivado/HLS 构建挂后台,期间做分析、写 TB、改文档,时间并轨;
- **诊断先行**:给 main.c 加诊断快照(失败时锁定瓦片/阶段/寄存器),再开始改任何东西;
- **反例保留**:被推翻的结论不删除,标注"已被 §5g 推翻"——技能的边界靠反例划出来;
- **交接即产品**:每次 session 结束更新 HANDOVER + SKILL + 备份锚点(ELF/bit/源),下一位可直接续跑。

## 4. 协作效率观察(给后来者)

1. **用户拍板节点精准**:"可以修改策略"出现在模型连撞三面墙之后,避免了继续在错误归因上空耗——方向级授权比逐条指令高效。
2. **物理操作不可替代**:POR、GUI 配置由用户完成,模型负责把"为什么、做完后跑什么验证"说清楚,衔接顺畅。
3. **模型的弱点也在暴露**:对寄存器级细节(AXI DMA 流口位宽、SLCR 分频字段)要靠试错补齐——用户评审过一遍的方案里仍有被工具"静默行为"打脸的情况,全部靠生成网表/ILA/对拍兜底才没酿成事故。
4. **文档是协作的复利**:SKILL.md 的每条规则都来自当日事故,后续同类问题(如 DAP wedge、数据腐烂)的定位时间从数小时降到分钟级。
