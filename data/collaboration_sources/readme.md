三份原件的大小、SHA256、归档 SHA256 及转换方式见 [provenance.json](provenance.json)。两份 Markdown 归档与原件逐字节相同；Word 正文归档使用 P001～P066 定位，段号不等同于页码。Word 不是 Markdown 的同稿排版版，它增加了 CRC 原型复用例，并更明确地限制了旧 HLS/cosim 经验的适用范围。

为复核整理稿中的历史描述，本轮另从工作区交接 v2/v3/v5 选入[带原始行号的摘录](handover_excerpts.md)，记录每份交接文件的整体哈希。它们支持追踪当时如何记录、撤回或修正判断；其中嵌入的摘要和日志片段仍不能自动替代完整原始实验日志。没有独立支持的数字只标为来源稿记载。

这些材料是用户提供的历史整理稿，不能仅因含引号就当作完整原始聊天导出。报告中的“用户提示词”短句按整理稿引述；“模型回答/动作”按来源内容摘述，不虚构大模型逐字回答、调用时间、会话 ID 或模型具体版本。原始测试日志、构建报告和当前可重复检查另列证据，不能由整理稿替代。

来源稿中的“永久禁区”“唯一门禁”“WHS<0.05 ns 必错”等表述保留作为纠错轨迹。**本目录不是现行操作手册，也不授予执行旧下载、复位或删除命令的权限。** 采纳后的操作流程以 [skill/readme.md](../../skill/readme.md) 为准。新证据推翻旧推断时，保留旧表述并说明修订理由。

本轮使用这些材料补齐的是设计报告中的协作与技能提炼过程。它们没有补齐当前 SSD95 集成版板测日志；未据此关闭冷启动、实时采集、机械跟随或 SD 存图验收。
