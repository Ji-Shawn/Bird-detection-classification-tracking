## 功能与分工

系统使用四路麦克风估计固定基座坐标系中的声源方向，控制水平云台寻向并进行竖直搜索。检测到鸟目标后，由视觉链路接管追踪；SSD 检测与鸟种分类为两个阶段。正式目标定位先给 NCC 和舵机控制服务执行机会，再补充鸟种分类结果。

Core0 负责图像与网络服务、识别调度、视觉追踪、舵机控制及照片生产。Core1 负责声音处理和 SD 文件系统写入。PL 提供摄像头采集、图像处理、HDMI、相关加速与接口逻辑。SD 启动的应用与电脑调试使用同一套算法和硬件；上位机用于显示、手动操作与在线调参。

SD 独立启动时，摄像头就绪且控制前置检查通过后，调用现有音视融合模式启动流程。明确的电脑手动或模式操作可以接管控制。程序不把启动失败视为已经进入融合，不绕过停止、控制权或过期检查。

## 视觉追踪与照片资格

以下两个门槛相互独立：

| 用途 | 当前规则 |
| --- | --- |
| 正式鸟目标检出与追踪 | SSD 鸟目标置信度严格大于 50% |
| 新照片记录资格 | 同一正式目标最近一次有效、已接受的 SSD 鸟目标置信度大于或等于 95% |

达到 95% 仍需本目标有效的视觉鸟种标签、新鲜完整画面和可用照片队列。声音分类结果、候选框、NCC 分数及鸟种分类置信度不能替代这项 SSD 门槛。目标切换、低分新结果、无效时间或过期证据会按原规则撤销记录资格。提高门槛不能保证消除高置信度误判。

持续纠偏使用新鲜正式 NCC 位置。位置过期或失配时，停止用旧坐标持续推进。控制输出为比例项、指令变化率限制及符合条件时的运动前馈；前馈依据图像和已接受的位置指令估计运动，不是编码器速度反馈。两轴独立控制，目标靠近中心时减速并保持。

## SD 照片流水线

1. Core0 在同一正式目标的视觉鸟种结果有效时，为新鲜完整画面附上 eBird 码、目标身份与分类时间。
2. 从 1920×1080 RGB565 完整画面按原流程采样，生成 640×360、24 位 BMP 完整照片；照片不是目标框裁剪图。
3. 使用两个 1 MiB 照片槽位发布完整、不可变的待写照片。队列繁忙时跳过照片，不阻塞追踪等待写卡。
4. Core1 单独持有 FatFs 和 SD 控制器，分步扫描目录、打开文件、分块写入、关闭文件并重命名。
5. 写入期间使用 `.tmp` 文件；完成后改名为 `.bmp`。未完成临时文件不算已保存照片。

共享描述区为 `0x3003f200`，总长 256 字节；照片槽位从 `0x37000000` 开始。跨核交接通过缓存维护、内存屏障及槽位状态完成。Core1 的 SD DMA 使用单独的非缓存区与中转缓冲，避免 AMP 条件下仅维护 L1 缓存产生旧数据。

最大生产频率为每秒 2 张。原有最多 2 秒失锁尾录窗口仍受标签、目标身份、SSD 资格和新鲜画面条件限制，不代表无目标时一直拍摄。文件系统服务采用分步处理，底层等待中定期让出声音服务；实际 SD 卡写入时延仍取决于卡和运行负载。

### 目录、日期与编号

SD 卡中的逻辑目录为：

```text
bird_class/
    date.txt
    comnig1_2026.10.29/
        1.bmp
        2.bmp
```

上例日期仅用于说明。固件在 FAT 文件系统中读取的名称是 `bird_class/DATE.TXT`；FAT 对大小写不敏感，仓库文件名可以保持小写。日期只来自卡内设置文件，格式为有效的 `YYYY.MM.DD`，年份支持 1980～2107。启动时读取一次，不使用电脑时间、编译时间、运行时长或未验证的实时时钟推算。跨日期使用须改卡内日期并重新上电。

缺失或无效日期会停止存图并报告错误，识别和追踪继续。已有日期不能在更新时被模板覆盖。每个鸟种、每个日期单独编号；重启扫描已有数字文件名后续号，不覆盖旧照片。已有 BMP、JPG、JPEG、PNG 和 TMP 数字文件均占用序号，因此断电恢复可能出现缺号。

只支持现有 FAT16/FAT32 流程，不执行格式化或自动删除旧文件。更新程序和设置文件时应保留用户照片。

## 四个板载按键

| 按键 | 功能 |
| --- | --- |
| KEY1 | 强制开启亮度增强，再按同键恢复自动 |
| KEY2 | 强制关闭亮度增强，再按同键恢复自动 |
| KEY3 | 关闭自动对焦，镜头 VCM 目标码值固定为 280 |
| KEY4 | 恢复自动对焦 |

按键对应 PL 管脚 N15、N16、T17、R17，低电平按下，30 ms 消抖，长按只触发一次。启动时已经按住的键需要先松开。KEY1/KEY2 同时触发时关闭优先；KEY3/KEY4 同时触发时恢复自动对焦优先。

亮度模式在有效帧边界切换，保留 LUT 就绪、异常旁路与亮区保护。码值 280 是镜头驱动设置，不代表距离、焦距或实际清晰度；接受命令与光学到位需要区别。

## 硬件与显示边界

本包采用 M48/M47 原摄像头转接板引脚，不能把 M111 新转接板接线直接用于本镜像。原接线中 PCLK 为 K17，HREF 为 K18，VSYNC 为 M20。其余接线以本包配对引脚表和约束为准。

麦克风阵列固定在基座，声音方位不叠加云台当前水平角。水平 PWM 中位为 1440 μs，范围 540～2480 μs，保留非线性标定与一次机构倍率计算；竖直启动为 1140 μs，自动扫描范围 540～1540 μs。

没有编码器。显示角度、PWM、变化率与接受状态都是指令或软件估计，不是实际机械角度和速度反馈。网络预览发布上限与摄像头物理采集频率分开控制；降低上位机预览频率不代表同步降低 HDMI 或识别使用的完整图像频率。
