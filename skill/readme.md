`zynq_pl_accel/` 是本项目积累的 Zynq PL 加速开发与排障经验，适合查阅数据通路问题、定点量化、验证方法和常用命令。

从 [zynq_pl_accel/skill.md](zynq_pl_accel/skill.md) 开始阅读。首次使用本项目时，先阅读根目录的 [readme.md](../readme.md)；运行和上板入口在 `board/`，构建入口在 `build/`。

查找当前代码位置请使用[源码导览](../src/readme.md)和[硬件导览](../src/pl/readme.md)。手册中的阶段编号和旧工程路径保留为经验案例，其当前目录对应关系见 `report/directory_reorganization.json`。本目录提供开发方法，实际运行命令以当前各目录的 `readme.md` 为准。
