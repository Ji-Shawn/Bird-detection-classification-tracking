# 可复制的模型任务提示词

这是待填写模板，没有完成实验或通过状态。复制下文，替换方括号中的内容，删除本次不适用的要求。

```text
任务：请针对 [具体功能/症状] 执行 [审查/定位/修改并验证]。

项目入口：[根目录与 readme 路径]
当前版本：[提交号、源码清单或固件/模型哈希]
硬件/工具：[器件、板卡、编译器、Vivado/HLS 版本]
允许操作：[例如只读审查；仅在临时输出目录运行离线测试；已授权的板卡操作范围]
不得改动：[本次明确排除的文件、固件或配置]

已提供证据：
- 输入：[文件路径、dtype、shape、布局、长度]
- 独立参考：[文件路径、生成方法、版本]
- 实际输出或失败日志：[路径]
- 相关源码与报告：[路径]
验收标准：[数值误差、比较数量、资源/时序预算、允许失败范围]

请先核对输入是否齐全以及结论需要哪一级证据。
围绕一个可证伪假设进行修改；保留原失败用例并复跑受影响边界情况。
缺证据时指出具体缺项，不生成不存在的实测值，不把解析/编译成功写成整机成功。
输出：具体改动、可复制命令、真实结果和证据路径、结论边界、仍未完成的验证。
```

用例一：把“优化性能”具体化为“固定输入和当前 bit/ELF，以某计时方法测量 30 次，报告预热方式、均值和最大值；只有得到基线后才改动”。其中次数和指标由本次任务决定，不能直接把模板示例当作实验记录。

用例二：把“看看时序有没有问题”具体化为“检查指定五份报告，输出资源与时钟摘要、缺失覆盖、CDC 待审查项；仅有汇总报告时不批准路径级豁免”。
