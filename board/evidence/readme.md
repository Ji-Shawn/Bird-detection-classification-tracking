## 哪些结论已经有证据

`history_models_20261002/` 是 2026-10-02 在 AX7020 上运行独立音频、图像分类和 SSD 测试程序的记录；还保留一份 2026-09-29 旧候选的失败日志。它包含实际硬件读回、原始文件指纹、当时 bit/ELF 指纹及测试边界。

这些历史测试所用的 bit、ELF、样本及运行方式，与 `board/firmware/` 中的当前集成固件不同。因此它们可以支撑开发过程、算子和模型支线验证及优化决策，不能替代当前 SSD95 集成固件的冷启动、实时采集、机械跟随和 SD 存图验收。

## 当前集成版本还需要收集什么

当前目录没有声称 2026-11-03 已新做整机板测。补交当前记录时，需要一起保存：

1. 测试时间、板卡型号、摄像头转接板版本、电源和 SD 卡信息；设备序列号可脱敏。
2. 实际使用的 BOOT、两核 ELF、bitstream、模型及输入文件的 SHA256。不要仅写“最新版”。
3. 运行命令、冷启动次数、每次运行时长、完整日志和异常记录。
4. 同一输入的实际输出与参考输出，包括比较口径、容差和未通过项；实际输出不能直接复制期望值。
5. 识别、实时预览、声音寻向、按键、SD 写图分别采用什么成功标准。没有编码器时，不把 PWM 指令变化写成实际机械速度。

运行时的临时日志通常位于 `build/out/board/`，默认不进入 Git。用于交付的结果应审核后选入本目录，以小写文件名保存，并在说明中注明它对应的固件版本和测试条件。
